WEB HOSTING & SCRATCH GUIDE

1. How to Host Your Game Online for Free

Save this file as index.html (or click Download index.html in the top bar). Upload that single file to Itch.io (select HTML project), GitHub Pages, or Netlify Drop to get an instant playable link!

2. Recreating AEGIS CORE in Scratch (2D Block Blueprint)

Because Scratch uses drag-and-drop blocks instead of 3D HTML/JS, build a 2D arena version using 4 sprites:

  • Player Sprite: Forever loop → point towards [mouse-pointer], move with WASD keys, and broadcast Shoot when mouse is down.
  • Laser Clone Sprite: When I start as a clone → go to [Player], point in direction ([direction v] of [Player]), repeat until touching edge or Monster → move (18) steps.
  • Monster Clones: Spawn every 2 seconds at random edges, point towards Player, move 3 steps, and if touching Laser → change Coins by 15 & delete clone.
  • Grapple Hook: When E pressed → glide 0.25s toward mouse x / mouse y!

3. Pro Combat Controls

1–6: Switch Weapons  |  Space (Hold): Jetpack Hover  |  Shift: Phase Dash  |  E / Right-Click: Grapple Hook  |  Q: EMP Shockwave
